# 果冻海 · JELLY SEA

一座悬浮在深空中的**正方形透明果冻生态岛屿**。沙盒内部同时拥有山脉、森林、草地、湖泊、沙滩、动态海洋、珊瑚礁与完整的海洋生物链。整个沙盒由程序化生成，没有外部模型与贴图依赖。

- 技术栈：Vue 3 · TypeScript · Vite · Three.js (WebGL2 / GLSL) · GSAP
- 默认视角：3/4 俯视，可同时看到沙盒轮廓、主山、海岸线与水下的立体生态

---

## 快速开始

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览 dist
```

浏览器要求：支持 WebGL2 的桌面 Chrome / Edge / Firefox / Safari（建议独立显卡，1920×1080 及以上体验最佳）。

## 实现要点

### 空间与构图
- `RoundedBoxGeometry` 构成 40 × 22 × 40 的圆角正方形果冻外壳，使用 **BackSide** 渲染内壁，避免顶面遮挡内部生态；底部叠加三层半透明果冻板与悬浮光晕，形成「悬浮生态岛」的厚度与轮廓。
- 地形为 180 × 180 的程序化高度场：径向主峰 + ridged fBm 山脊 + 斜向海岸 + 海床盆地；顶点色混合草地、沙地、岩石、雪线与海底深色，并注入动态焦散光斑。

### 果冻 / 水 / 光
- 自定义果冻 Shader：菲涅尔透明、内部流动噪波、上下边缘青色辉光、紫色渐变。
- 水面 Shader：三层正弦波叠加 + 世界空间深度渐层 + 菲涅尔天空反光 + 波峰高光 + 岸边浪花 + 水下体积光柱。
- 光照：半球光 + 主方向光（1024 阴影）+ 紫罗兰轮廓光 + 水下青色补光；ACES 色调映射 + 低强度 Bloom，避免过曝。

### 生态
- 48 棵树（针叶 / 阔叶）、灌木、720 丛草、140 朵花、岩石全部使用 `InstancedMesh`，顶点着色器注入风摆并支持每实例颜色。
- 鲸鱼：程序化身体 + 尾鳍摆动 + 顶点波动 + Catmull-Rom 闭环巡游；水母：呼吸式脉动 + 触须漂摆 + 6 只不同配色；鱼群：3 群 78 条，**运动完全在顶点着色器内完成**（0 CPU 开销）；另有海龟、螃蟹、海星、珊瑚、海草、发光浮游生物。
- 果冻颗粒：最多 12,000 个 `Points`（默认 5,000，可实时调节），叠加气泡、近景晶体颗粒与海底发光浮游生物。

### 交互与 UI
- 统一 Ticker + 共享 `uTime`：暂停即冻结全部 shader 动画，相机与 UI 不受影响。
- GSAP 平滑切换四个视角；进入水下时外壳自动淡出、切换水下雾效与近裁剪面。
- 玻璃拟态 UI：顶部标题、右侧生态状态、底部控制栏、物种档案卡、载入进度层。

## 性能说明

- 渲染目标分辨率固定为 CSS 像素（`EffectComposer.setPixelRatio(1)`），DPR 上限 1.5，避免高分屏过度采样。
- 阴影贴图 1024，仅树木 / 建筑 / 鲸鱼投射；地形只接收阴影。
- 所有重复物体 InstancedMesh / InstancedBufferGeometry；主循环无每帧几何体或材质创建。
- 页面缩放通过 `resize` 重建尺寸；卸载时统一 dispose。
- 帧率上限取决于显示器刷新率（本机为 25 Hz 环境，场景本身不是瓶颈）。在 60 Hz 显示器上可达到 60 fps。
